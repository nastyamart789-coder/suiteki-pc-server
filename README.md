# Suiteki PC Server

ПК-сервер для приложения **Suiteki** — чат-ботов с персонажами.

Связывает мобильное приложение с [Ollama](https://ollama.com) на вашем ПК.
Все AI-модели работают **локально** — без облаков, без подписок, без утечек данных.

---

## Что это

**Suiteki PC Server** — настольное приложение для Windows, которое:

- Устанавливает **Ollama** одной кнопкой
- Позволяет скачивать и удалять AI-модели прямо из GUI
- Поднимает локальный HTTP-сервер на порту `5000`
- Связывает мобильное приложение **Suiteki** с моделями на вашем ПК
- Синхронизирует выбранную на телефоне модель с сервером

Телефон отправляет сообщения на ваш ПК → ПК генерирует ответ через Ollama → ответ возвращается на телефон.
Интернет не требуется — только Wi-Fi между телефоном и ПК.

---

## Требования

| Компонент | Минимум | Рекомендуется |
|---|---|---|
| ОС | Windows 10 (64-bit) | Windows 11 |
| RAM | 8 ГБ | 16 ГБ |
| Свободное место | 10 ГБ | 30 ГБ |
| Сеть | Wi-Fi адаптер | Ethernet + Wi-Fi |
| Python | **не нужен** (встроен) | — |

**Почему нужен ПК?** Мобильные модели ограничены в размерах. Полноценные модели на 7–9 миллиардов параметров отлично работают на ПК, а телефон выступает в роли клиента.

## Быстрый старт

### 1. Скачайте архив

Скачайте последнюю версию `server.zip` со вкладки **[Releases](../../releases/latest)**.

### 2. Распакуйте

Распакуйте архив в любую папку, например: `C:\SuitekiServer\`.

> ⚠️ **Важно:** папка `python/` должна лежать рядом с `run.bat` — не перемещайте файлы по отдельности.

### 3. Запустите

Двойной клик по **`run.bat`** (или `launcher.exe`, если он есть).

Откроется окно GUI — «🚀 ChatBot ПК-Сервер».

### 4. Установите Ollama

На вкладке **«🔧 Установка»**:

- Нажмите **«🔧 Установить Ollama»** — GUI сам скачает и установит Ollama в фоне.
- Дождитесь статуса **«✅ Ollama установлен»**.

### 5. Скачайте модель

Перейдите на вкладку **«🤖 Модели»**:

- Выберите модель (для старта рекомендую **Phi-3 Mini** или **Llama 3.2 3B**).
- Нажмите **«📥 Скачать»**.
- Дождитесь завершения (индикатор прогресса покажет статус).

### 6. Запустите сервер

Вкладка **«🌐 Сервер»** → **«▶ Запустить сервер»**.

В окне появится сообщение с IP-адресом, например:
✅ Сервер запущен!
IP: 192.168.137.1
Порт: 5000

text

### 7. Разрешите доступ в брандмауэре

При первом запуске **Windows спросит разрешение**:

> «Разрешить приложению Python обмен данными в частных и общедоступных сетях?»

✅ **Обязательно нажмите «Разрешить доступ»**. Иначе телефон не сможет подключиться.

### 8. Подключите телефон

Откройте приложение **Suiteki** на телефоне:

1. Настройки → **Онлайн-режим** — включён.
2. Раздел **«Модели»** → вкладка **«🌐 Серверные»**.
3. Введите IP с ПК (тот, что показан в GUI).
4. Порт: `5000`.
5. Нажмите **«Подключиться»**.
6. Выберите модель из списка.
7. Перейдите в **«Чаты»** → откройте любого персонажа → общайтесь!

## Как это работает
┌──────────────┐ Wi-Fi ┌──────────────────┐
│ Телефон │ ◄──────────────► │ Ваш ПК │
│ Suiteki │ HTTP :5000 │ Suiteki Server │
└──────────────┘ │ │ │
│ ▼ │
│ ┌──────────┐ │
│ │ Ollama │ │
│ │ :11434 │ │
│ └──────────┘ │
│ │ │
│ ▼ │
│ AI-модель │
│ (локально) │
└──────────────────┘

text

1. Телефон отправляет сообщение на `http://<IP_ПК>:5000/api/chat`.
2. Сервер пересылает запрос в Ollama на `localhost:11434`.
3. Ollama генерирует ответ с помощью установленной модели.
4. Сервер возвращает ответ на телефон.

**Важно:** выбор модели происходит **на телефоне**. ПК-сервер сам подстраивается под запрос и сохраняет выбор в `current_model.txt`.

## Подключение телефона

### Способ 1. Через Wi-Fi роутер (рекомендуется)

1. ПК и телефон — в **одной сети Wi-Fi**.
2. Запустите сервер на ПК.
3. Скопируйте IP с вкладки «🌐 Сервер» в GUI.
4. Введите IP в приложении на телефоне.

### Способ 2. Через мобильный хот-спот Windows

Если общего Wi-Fi нет:

1. На ПК: **Параметры → Сеть → Мобильный хот-спот** → включить.
2. На телефоне: подключиться к этому хот-споту.
3. Запустить сервер на ПК.
4. В GUI обычно IP = `192.168.137.1`.
5. Ввести этот IP в приложении.

> 💡 **Совет:** не забудьте включить мобильный хот-спот ДО запуска сервера, иначе IP может определиться неверно.

## Решение проблем

### Телефон не подключается

- ✅ Проверьте, что ПК и телефон в **подключены через хот-спот**.
- ✅ Убедитесь, что в брандмауэре Windows **разрешён доступ** для Python/launcher.exe.
- ✅ Нажмите **«🔄 Обновить IP»** в GUI — возможно, IP сменился.
- ✅ Проверьте, что сервер **запущен** (зелёный статус на вкладке «🌐 Сервер»).

### Сервер не запускается

- ✅ Проверьте, что **Ollama установлена** (вкладка «🔧 Установка»).
- ✅ Откройте вкладку **«📋 Логи»** — там будет точная причина.
- ✅ Перезагрузите ПК и попробуйте снова.

### Ollama не отвечает

- ✅ Откройте командную строку и введите: `ollama serve`.
- ✅ Если команда не найдена — переустановите Ollama через GUI.
- ✅ Антивирус может блокировать Ollama — добавьте её в исключения.

### Модель скачивается слишком долго

- ✅ Модели весят 2–5 ГБ — это нормально.
- ✅ Скорость зависит от интернета на ПК.
- ✅ Можно поставить загрузку на ночь.
- ✅ В логах отображается прогресс скачивания.

### Приложение пишет «Сервер не отвечает»

- ✅ Убедитесь, что сервер запущен на ПК.
- ✅ Проверьте, что IP в приложении совпадает с IP в GUI.
- ✅ Попробуйте перезапустить сервер.
- ✅ Проверьте брандмауэр.

### Порт 5000 занят

Если порт 5000 занят другой программой:

1. Откройте `server_setup.py` в блокноте.
2. Найдите строку `port=5000`.
3. Замените на другой порт, например `port=5001`.
4. В приложении на телефоне укажите новый порт.
